Purpose of the Study

You are invited to participate in a research study on content-based artwork recommendation using the WikiArt dataset. A recommendation system can automatically adapt content to each individual’s personal preferences. Two common approaches are content-based filtering and collaborative filtering. Content-based filtering is a recommendation system approach that suggests items (in this case paintings) similar to those the user liked in the past based on specific features (e.g. artist, style, genre, colour scheme, etc...). On the other hand, collaborative filtering recommends paintings that are preferred by users with similar taste profiles, based on the users’ interaction with items. This Final Year Project implements a content-based filtering approach. Therefore, paintings will be recommended based on the features of artworks that a user has previously indicated they like. To determine user preferences, both implicit and explicit feedback will be collected. This feedback allows the system to iteratively refine and personalise future recommendations, improving their relevance to each individual user. The recommendation system is presented as a website with an interface similar to widely used social media platforms (e.g., Pinterest). As part of evaluating the system’s performance, the collected user feedback will be analysed to examine how participants interact with the online art recommendation platform. This analysis will help determine which recommendations were most effective or meaningful, as well as assess the overall quality of the system’s recommendations. This means that by using the website the user is providing data including the time spent viewing a painting, click streams, liked/disliked paintings, as well as painting ratings and reviews. However, a more detailed explanation of how and what user data is collected will be discussed in the following sections. Additionally, by using the Create Your Own Art function of the website (Create Tab → Create Art Section → Create Your Own Art Page), the user can upload a photo and painting of choice to create a new painting based on the photo using the art style of the painting uploaded. Then the generated painting will be added to the dataset and subject to recommendation on the Home page for all the users viewing the website. Overall, the purpose of this study is to gain insights into user preferences and interaction behaviour, which will help improve the design and effectiveness of the artwork recommender system.

What Participation Involves

Participation in this study is expected to take approximately 5-10 minutes, which should be sufficient to gather a meaningful amount of user feedback per user. The user will need to access and use the website to browse and interact with artworks. As mentioned earlier, participants will be required to provide implicit feedback, such as click streams and per painting viewing time which are passively collected through system tracking. This means that data is collected without the user actively choosing to provide feedback and is gathered continuously throughout the entire period during which the user is using the website. This approach offers a seamless user experience and behavioural insight, however it’s usually less precise, because interest is inferred rather than directly stated. Hence, it’s paired with explicit feedback, such as star ratings, favourite/not interested symbol, optionally submitting reviews or save to gallery, which involves active user engagement. Such feedback provides clear, intentional signals about user preferences but requires direct user input. Such interactive feedback will be collected, allowing users to immediately indicate whether they liked or disliked recommended artworks, thereby providing relevance judgments that support iterative refinement to the recommendations made to that user in particular. As mentioned in the previous section, the generated images (from the Create Your Own Art function) will form part of the artwork dataset, making these images subject to recommendation for all the website users. So, it’s important that any photos uploaded for generation don’t include sensitive content (e.g., faces, number plates, etc...), or else they will be removed.

Data Collection and Use

Participants’ identities will not be recorded at any stage of the research, hence all data, including consent forms and user feedback from the website, will be anonymous and no identifying information will be collected (e.g. name, email, etc...). All data collected through the website will be anonymous at the point of collection, and will be stored/retrieved/deleted from a Database only accessible by myself. No information will be collected beyond what is strictly necessary for the study (i.e. implicit and explicit user feedback as well as AI generated images by the user). Hence, only the resulting AI generated painting will be stored within the dataset, meaning any uploaded reference photos/paintings will be discarded upon creation of the new painting. User interaction data and feedback will be stored in digital form (i.e. the Database) and used solely for research purposes. Hence, the database will include columns representing different types of feedback (e.g. likes, time spent viewing a painting, etc...). Each row will correspond to a specific painting-user interaction and will record the relevant feedback values alongside an anonymised user identifier (e.g. User 21), thereby preserving participant anonymity while still allowing all interactions associated with a given user to be tracked. Since this recommender system is content-based, meaning that recommendations are generated based on paintings with similar features rather than users with similar taste profiles, the feedback collected will be used solely to refine per-user recommendations and to support the overall analysis and detailed evaluation of user preferences across all website users. Participation is entirely voluntary, and you may withdraw at any time without penalty.

Potential Benefits

Recommender systems are used in everyday life, such as when browsing social media platforms like Instagram, TikTok, YouTube, online shopping, etc.... Hence, this project will increase awareness of how user-provided data is collected, represented, and utilised within recommendation algorithms, as well as how such data influences personalised content delivery. Due to the increasing popularity of recommendation systems, raising awareness of how they operate and the effects of passive content consumption can encourage users to engage more critically with digital platforms and make more informed decisions about their online interactions and data sharing. By interacting with the system, participants gain insight into the trade-offs between personalisation, diversity, and transparency, creating more informed and critical engagement with recommender systems. At a broader societal level, the project contributes to discussions on responsible and explainable recommender systems, supporting the development of more transparent systems.
