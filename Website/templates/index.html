Adjust User Profile Weights

The user profile is a representation of your preferences based on previous interactions with paintings e.g., adding to favourites, skipping, ratings, and so on. While using the website explicit and implicit feedback are collected, allowing users to indicate whether they liked/disliked recommended paintings, thereby providing relevance judgments that support iterative model refinement. Explicit feedback involves active user engagement, providing intentional signals about user preferences. In contrast, implicit feedback is gathered passively by monitoring user behaviour, however it’s less precise, since interest is inferred rather than directly stated.

Explicit Feedback
  • Rating: Prioritises paintings according to the rating.
  • Favourite: Increases recommendations similar to these artworks.
  • Not Interested: Reduces recommendations similar to these paintings.
  • Reviews: Uses written engagement as preference feedback, however this is unreliable since the user can enter both positive and negative reviews.
Implicit Feedback
  • Dwell Time: The longer you view paintings indicates interest, however dwell time is capped at 1 minute.
  • Clicks: Uses selected paintings as an indication of interest.
  • Skip: Penalises ignored recommendations, according to their position in the ranked list of retrieved paintings.

The sliders below allow you to adjust how strongly each interaction influences your recommendations, according to your preferred forms of feedback.
